# Citations Pending Verification

**Rules:**
1. Never copy an unverified entry from this table into [`references.bib`](references.bib).
2. Whenever an agent encounters an unverified citation, add a row here **and** open an escalation ticket in [`escalations/README.md`](../escalations/README.md).
3. Once a human maintainer verifies all required fields ([`bibliography/README.md`](README.md)), add the BibTeX entry to [`references.bib`](references.bib) and mark the row `verified (moved)` (or remove it after recording the resolution in the linked escalation).
